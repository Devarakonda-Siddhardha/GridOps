# ⚡ Pantheon's Wrath: Champions of Hellas

**Official Windows 64-bit Standalone Release (v1.0.0)**

---

## 🎮 How to Play on Windows
1. Download **`PantheonsWrath_Windows_x86_64.zip`**.
2. Extract the contents to any folder on your Windows PC.
3. Double-click **`PantheonsWrath.exe`** to launch the game!

---

## ⚔️ Controls
- **WASD / Arrow Keys**: Move warrior
- **Left Mouse Click / Spacebar**: 3-Hit Melee Combo
- **Shift**: Tactical Dodge Roll (with invincibility frames)
- **E**: Pray at God Altars
- **Number Keys (1, 2, 3, 4)**: Activate God Powers:
  - **[1] Zeus**: Chain Lightning / Thunderbolt
  - **[2] Poseidon**: Tidal Wave Shockwave
  - **[3] Hades**: Underworld Shadow Grasp
  - **[4] Ares**: Spartan Berserk Fury (2x Damage & Speed)
- **Tab**: Divine Pantheon Codex & God Favors
- **Esc**: Pause Menu / Audio & Video Settings
